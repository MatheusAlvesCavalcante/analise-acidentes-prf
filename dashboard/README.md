##  Como Executar

Para rodar este dashboard localmente, siga os passos abaixo:

### 1. Requisitos
Certifique-se de ter o Python 3.9 ou superior instalado.

### 2. Instalação
Navegue até a raiz do projeto e instale as dependências necessárias:

```bash
pip install -r dashboard/requirements.txt
```
### 3. Execução streamlit run dashboard/app.py
